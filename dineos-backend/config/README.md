# Firebase Service Account Key

Place your `serviceAccountKey.json` file in this directory.

⚠️  This file is git-ignored and should NEVER be committed to source control.

## How to get it:
1. Go to Firebase Console → Project Settings → Service Accounts
2. Click "Generate new private key"
3. Rename the downloaded file to `serviceAccountKey.json`
4. Place it here: `admin-backend/config/serviceAccountKey.json`
